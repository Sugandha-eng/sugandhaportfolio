Collaborative Whiteboard


Collaborative Whiteboard is a real-time web application that enables multiple users to draw, write, and collaborate simultaneously on a shared digital canvas. Built with React.js, Node.js, Express.js, and Socket.IO, the application provides instant synchronization of user actions through WebSockets, ensuring a seamless collaborative experience. It features an intuitive and responsive interface with drawing tools, freehand sketching, shape creation, and live updates, making teamwork interactive and efficient. The project follows a scalable client-server architecture and leverages version control practices to support maintainability, real-time collaboration, and future feature enhancements.
